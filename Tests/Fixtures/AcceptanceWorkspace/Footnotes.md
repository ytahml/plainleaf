# Footnotes in Plainleaf

Technical writing often needs a quiet place for evidence without interrupting the sentence.[^source]

The same source can be cited again,[^source] while a second note can add bilingual context.[^context]

## Reading notes

Footnote numbers should stay compact, keyboard-focusable, and visually subordinate to the prose. Selecting one moves to its note; the return mark moves back to the exact reference.

[^context]: 中文脚注与 English context should share the same calm reading rhythm.
[^source]: Plainleaf keeps the note in ordinary Markdown.
    Continued lines can include **emphasis**, `inline code`, and [local links](Guides/Writing.md).

    A second paragraph remains part of the same definition.
