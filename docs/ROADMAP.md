# Roadmap after the MVP

## Delivered locally

- Document outline with duplicate-safe HTML anchors, hierarchical sidebar navigation, active-section tracking, a persisted collapse state, and `Option-Command-O`
- In-memory full-workspace Markdown search with path/content results, line snippets, source selection, and `Shift-Command-F`
- Draggable source/HTML split view with bidirectional proportional scroll synchronization and `Shift-Command-R` three-mode cycling
- Semantic footnotes with first-reference numbering, multiline definitions, repeated-reference return links, and local fragment navigation
- Persisted reading appearance with bounded text size, named line-spacing and page-width presets, and keyboard controls
- Standalone UTF-8 HTML export with embedded local images, safe portable links, current appearance, and atomic user-selected writes
- Bundled offline LXGW WenKai GB Lite reading font and public source repository
- Preview render reuse for scroll-only updates and save/conflict protection on normal application quit
- Ad-hoc signed ZIP packaging, checksums, bundled licenses, and CI/tag-to-draft-release configuration (remote execution tracked separately in the acceptance report)

## Still deferred

The following capabilities remain intentionally deferred:

1. Multiple windows and document tabs
2. Math and Mermaid
3. Managed image import and configurable asset rules
4. Custom CSS themes
5. Dedicated PDF export
6. Chinese localization
7. Developer ID signed and notarized distribution
8. Community contribution workflow

Cloud sync, collaborative editing, AI writing, a plugin ecosystem, and blog publishing require separate product decisions rather than being assumed roadmap commitments.
