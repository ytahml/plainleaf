# Roadmap after the MVP

The following capabilities remain intentionally deferred:

1. Multiple windows and document tabs
2. Full-text workspace search and document outline
3. Split preview and synchronized scrolling
4. Footnotes, math, and Mermaid
5. Managed image import and configurable asset rules
6. Custom CSS themes, bundled open fonts, and font controls
7. Dedicated PDF and standalone HTML export
8. Chinese localization
9. Signed and notarized distribution
10. Community contribution workflow and public repository

Cloud sync, collaborative editing, AI writing, a plugin ecosystem, and blog publishing require separate product decisions rather than being assumed roadmap commitments.
